# 配置

## 水平二连杆模型

`two_link_arm.xml` 对应原 ArmLab 的水平 x-y 平面二连杆。长度为 0.30、0.25 m；q1 相对世界 +X，q2 相对第一杆，绕 +Z 逆时针为正；内部单位为 m、rad、s。

教学参数（不是硬件实测值）：

| 参数 | 第一杆 | 第二杆 |
| --- | ---: | ---: |
| 质量 / kg | 0.30 | 0.25 |
| 圆柱杆半径 / m | 0.01 | 0.01 |
| 质心沿杆位置 / m | 0.15 | 0.125 |
| 关节黏性阻尼 / (N·m·s/rad) | 0.02 | 0.02 |
| 关节限位 | ±150° | ±150° |
| 力矩输入限制 / N·m | ±1 | ±1 |

MuJoCo 根据均匀圆柱的几何与指定质量生成质心和惯量；绕质心垂直杆方向的惯量为 `m*(L²+3*r²)/12`，是此前细杆近似 `m*L²/12` 加上有限半径修正，后续解析动力学须使用这里的参数。关节摩擦损耗和额外转子惯量均设为零。

运动平面在 z=0.08 m，重力保留为沿 -Z；理想水平两转轴的广义重力力矩为零。障碍为竖直圆柱，其截面圆心 (0.15,0.08) m、半径 0.04 m。两根相邻杆互相不接触，底座仅用于显示；这不是完整自碰撞模型。

杆碰撞几何使用有限圆柱，原解析检查使用线段加杆半径的保守包络，二者在杆端附近不完全相同；不能据此声称两套碰撞判定已逐项一致。

执行器为直接力矩 motor，gear=1，ctrl 单位 N·m；没有内置位置伺服或用户 PD 控制器。步长 0.002 s，积分器 implicitfast。力矩限制只是初始教学选择，尚未通过跟踪实验验收。

在项目根目录打开：

```powershell
.\.venv\Scripts\python.exe -m mujoco.viewer --mjcf=configs/two_link_arm.xml
```

本模型由 AI 在学习者明确要求下创建。加载与运动学验证不等于完成动力学交叉验证或轨迹跟踪控制。
