# 实验 05：二连杆 A* 规划、Dijkstra 对照与网格分辨率

> 整理日期：2026-10-15。依据学习者当前实现、其反馈的运行输出，以及 AI 在内存中运行的对照实验整理。已实现、已测试不等于全部知识点已经独立掌握。

## 问题与预测

- **本次验证：** 在带单圆障碍的平面二连杆关节空间中，A* 能否返回通过离散连接检查的路径；能否正确处理无效输入与搜索耗尽；与 Dijkstra 的代价是否相同；网格变细后探索量与路径代价如何变化。
- **预测依据：** 欧氏启发式忽略障碍和绕行，不高估图中实际剩余代价，且与欧氏边代价满足一致性。相同图上 A* 与 Dijkstra 应得到相同的最优代价，但节点序列不必相同。细网格提供更多候选姿态，也增加搜索规模，不保证每个场景的路径都更短。
- 上述是方法上的预期；未完整保留学习者在全部对照运行前的个人预测，不将事后解释补写成个人事前预测。

### 场景与算法

| 项目 | 设置 |
| --- | --- |
| 杆长 | a1=0.30 m，a2=0.25 m |
| 障碍物 | 圆心 (0.15, 0.08) m，半径 0.04 m |
| 连杆半径 | 0.01 m |
| 关节限位 | 两关节均为 [-150°, 150°]，不做周期绕回 |
| 起点、目标 | [0°, 0°] → [-75°, -150°] |
| 基础网格 | [-150°, -75°, 0°, 75°, 150°]，5×5 |
| 节点约定 | (j, i)：行是 q2，列是 q1；函数内部角度用弧度 |
| 邻接 | 四邻居；节点有效且连接采样通过才形成边 |
| 边代价 | 两节点关节角向量的欧氏距离，单位 rad |
| 启发式 | 当前关节角到目标关节角的欧氏距离，单位 rad |
| 基础连接检查 | 每边 76 点，含端点；75° 边对应 1° 间隔 |
| 随机种子 | 不适用，算法无随机采样 |

搜索流程：起终点有效性检查 → 起点入堆 → 弹出最小 f 记录 → 跳过过期记录 → 判断目标 → 筛选邻居 → 更小 g 才更新 g、parent 并入堆 → 回溯返回路径。失败返回 `None`；示例在函数返回后逐段复核路径。

过期判断使用出队记录 `best_f > g[current] + h_current`。队列保存 `(f, node)`；完全相同的 f 用节点元组决定先后，近似相同的浮点数仍按实际值比较。

### 对照设置与计数

- **Dijkstra：** AI 读取现有搜索函数，在内存中将 `h_start`、`h_current`、`h` 三处赋值置为 0，保留边代价、碰撞接口、队列和回溯逻辑。没有修改源文件或保存验证脚本。
- **网格：** 分别使用 `np.arange(-150, 151, step)`，step 为 75、25、5 度。由相同起终点角度重新查找索引，不直接复用 `(2,2)` 和 `(0,1)`。
- **采样控制：** 每条边使用 `sample_count=step+1`，即 76、26、6 点，统一 1° 连接检查间隔；不把网格加密与边检查加密混为同一因素。
- **扩展次数：** 统计通过过期判断、非目标、实际执行邻居扩展的次数；不含目标出队及过期跳过。
- 路径代价由返回路径的各段欧氏角距离重新求和；每一段使用同一连接接口复核。复核是集成检查，未采用独立的连续碰撞求解器。

下列片段可在已有导入与实验环境中复现网格比较，不需要写入源文件：

```python
params = (0.30, 0.25, 0.15, 0.08, 0.04, 0.01)
for step in (75, 25, 5):
    angles = np.arange(-150, 151, step)
    grid = build_valid_grid(angles, *params)
    def index_of(q1, q2):
        i = int(np.flatnonzero(angles == q1)[0])
        j = int(np.flatnonzero(angles == q2)[0])
        return j, i
    path = astar_search(
        index_of(0, 0), index_of(-75, -150), grid, angles,
        *params, sample_count=step + 1,
    )
```

## 结果

### 基础搜索与回溯

目标出队前的扩展顺序：

```text
(2,2) → (1,2) → (0,2) → (1,1)
```

随后目标 `(0,1)` 出队。最终返回：

```text
节点：(2,2) → (1,2) → (1,1) → (0,1)
角度：[0°,0°] → [0°,-75°] → [-75°,-75°] → [-75°,-150°]
```

- 累计代价：`3.9269908169872414 rad`。
- 三段连接复核均为 `True`。
- `(0,2)` 是探索分支，未进入最终路径。其向目标的连接在采样姿态 [-2°, -150°] 检出碰撞。
- 右侧分支在 [11°, 0°]、[11°, -75°] 等采样点检出碰撞。“首次无效”只是有限采样中的首个检出点，不是精确接触边界。

### Dijkstra 对照

| 指标 | A* | Dijkstra（h=0） |
| --- | ---: | ---: |
| 路径代价 / rad | 3.926990817 | 3.926990817 |
| 扩展次数 | 4 | 8 |
| 路径节点数 | 4 | 4 |
| 三段复核 | 全部通过 | 全部通过 |

两者本次返回相同节点序列。当前案例 A* 扩展次数减少一半；本次没有测量运行时间，不据此声称运行速度提高一倍。

### 网格分辨率

| 间隔 | 网格 | 有效节点 | 路径节点 | 扩展次数 | 过期跳过 | 路径代价 / rad | 连接复核 |
| ---: | --- | ---: | ---: | ---: | ---: | ---: | --- |
| 75° | 5×5 | 23 | 4 | 4 | 0 | 3.926990817 | 全通过 |
| 25° | 13×13 | 151 | 10 | 23 | 1 | 3.926990817 | 全通过 |
| 5° | 61×61 | 3215 | 46 | 588 | 13 | 3.926990817 | 全通过 |

三者代价相同：四邻居的轴向运动可实现无角度折返的路线，累计变化为 75°+150°=225°≈3.927 rad，已达到该图的这项代价下界。更细网格增加了节点与扩展量，但本场景未展示“粗网格失败、细网格成功”的通道案例。

25°、5° 两组实际执行了过期记录跳过分支。此次只观察到了该分支执行，没有保存每条旧记录的完整诊断过程。

| 案例 | 实际结果 |

| 起点 (4,2)，目标 (0,1) | 提前报告起点无效，返回 None |

## 修正与理解

### 调试与修正

- 加入 while 后，邻居更新循环一度未正确放进搜索循环，起点出队后队列即为空；根据没有出现邻居代价打印定位缩进问题，修正后连续探索到目标。
- 旧的两个节点验证循环被放进每轮搜索，造成重复碰撞输出；删除重复验证后输出与每轮搜索对应。
- 起终点最初仅打印有效性，没有提前返回；加入两个有效性分支后，无效姿态在搜索前被拒绝。
- 封装后曾只打印路径而没有返回，调用处仍显示“没有返回路径”；后来又把 return 放进复核循环，存在第一段即返回和单节点路径不返回的问题。最终在回溯反转后统一 return path，复核留在示例。
- 分清两类比较：`tentative_g < 旧g` 决定是否采用更短路线；`出队旧f > 最新f` 决定是否跳过过期记录。

### 本阶段的理解与边界

- 节点是完整机械臂姿态；关节空间连接不等于末端空间直线。
- 普通节点 f 是总代价估计，不是已经找到的完整路径代价；目标出队时 h=0。
- 搜索顺序不等于最终路径；parent 用于从目标回溯，反转后才得到执行方向的候选路线。
- Dijkstra 是 h=0 的搜索对照，不是 A* 运行的必要组件。
- 当前最优性针对离散图与所定义的关节角距离代价，不代表连续空间最短路径或最短执行时间。
- “图中没有路线”不等于连续空间无解；“全部采样通过”不等于严格连续安全证明。
- 当前函数仍以方形、同一角度数组的四邻居网格为前提；输入形状、索引范围、NaN 等通用参数校验并未完整验收。
