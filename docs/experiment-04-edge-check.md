# 实验 04：关节空间直线连接的离散碰撞检查

> 记录日期：2026-09-25。本报告依据学习者编写的实验代码、其提供的运行输出，以及本次复跑结果整理。它记录采样检查的行为，不将离散通过写成连续运动安全证明。

## 问题与预测

- **这次只验证什么？** 起点和终点姿态均有效时，沿两关节角的直线插值检查中间姿态；比较采样点数对碰撞检出结果的影响。
- **运行前我认为会发生什么？为什么？** 学习者已根据构型空间地图指出，端点安全不代表中间安全，并预测 (0°, 0°) 到 (60°, 0°) 会穿过红色碰撞带。对不同采样点数的逐项事前预测没有完整记录，不能事后补写。

### 模型、场景、参数、种子

- 平面二连杆长度：0.30 m、0.25 m；两关节限位均为 ±150°。
- 静态圆形障碍：圆心 (0.15, 0.08) m，半径 0.04 m；连杆半径 0.01 m。
- 连接起点：`q_start = (0°, 0°)`；终点：`q_goal = (60°, 0°)`。代码内部用弧度。
- 采样点数：2、3、11、61，均通过 `np.linspace(0, 1, sample_count)` 包含两个端点。
- 随机种子：不适用，本实验无随机采样。

### 对照方法与指标单位

- 对每个比例 `s` 计算 `q(s) = (1-s) q_start + s q_goal`，并调用 `is_pose_valid`。
- 任一采样姿态无效，连接检查立即返回 `False`，并打印首次检出的 `s` 与关节角（度）；全部采样点有效则返回 `True`。
- `sample_count < 2` 时函数抛出 `ValueError`，防止只检查起点或空循环直接返回通过；此边界分支本次未单独执行验收。
- 这是关节空间的直线，末端在 XY 平面中的轨迹不一定是直线。

## 结果

### 实际数据与图表位置

本次复跑 [实验脚本](../examples/edge_check_exp.py) 的结果：

| 采样点数 | q1 相邻采样间隔 | 连接检查结果 | 首次检出的无效姿态 |
| ---: | ---: | --- | --- |
| 2 | 60° | `True`，未检出碰撞 | 无 |
| 3 | 30° | `False` | `s=0.50`，(30°, 0°) |
| 11 | 6° | `False` | `s=0.20`，(12°, 0°) |
| 61 | 1° | `False` | 输出 `s=0.18`，(11°, 0°) |

`s=0.18` 是保留两位小数后的打印值；该采样点实际为 `11/60≈0.1833`。本次没有生成新图表或单独保存原始终端日志；上述结果可用给出的命令复现。

此前的独立实验还核对了同一安全姿态作为起终点时返回 `True`。这次复跑的脚本仅包含表中四种采样点数。

### 和预测一致／不一致的地方

- 加入中间点后，连接被判为无效，符合“直线穿过碰撞带”的预测。
- 仅取两个端点时返回 `True`，表明它漏检了中途碰撞。学习者据此总结：只检查起终点会得出错误结论。
- 采样加密后，首次检出的角度从 30°、12°变为 11°；这些角度是**首次被采样到的碰撞姿态**，不是精确的连续碰撞边界。

### 失败案例及原因证据

- **漏检案例：** 2 点检查只有 (0°, 0°) 和 (60°, 0°)，两者均有效，因而返回 `True`；同一段连接在 3、11、61 点检查中都返回 `False`。这直接证明当前 2 点离散检查会错过此场景的中间碰撞。
- **实现时的诊断输出问题：** 初次加入“首次发现无效”打印时，该语句位于 `if not valid` 外，安全姿态也逐次打印。学习者将打印移入该分支后，输出只在首次无效姿态出现一次。报告不把这一输出问题写成碰撞算法本身的误判。
- 即使 61 点检查返回 `True`，也只能说明这 61 个姿态未检出碰撞；采样点之间仍可能发生碰撞。

## 修正与理解

### 我犯了什么错，如何定位？

- 最初把整张构型空间地图的双层扫描循环复制进连接实验，尚未使用插值得到的 `q` 检查当前姿态。经代码审阅后改为只沿一条连接插值的一层循环。
- 初次封装后，调用处打印了函数内部的 `valid` 变量；后改为接收并打印 `is_edge_valid` 返回值。
- “首次发现无效”打印原先未放入 `if not valid` 分支；观察安全案例也打印该句后调整缩进。

### 修改后如何验证？

- 已知碰撞连接 `(0°, 0°) → (60°, 0°)` 在 11 点检查中返回 `False`；同一安全姿态作为起终点时返回 `True`，学习者提供运行输出。
- 本次将同一连接的采样点数改为 2、3、11、61 并复跑，得到上表结果。
- 本报告仅记录并复核，未修改学习者的连接检查实现。

### 本次能解释的知识点

- 学习者已指出：只检查起终点会漏掉中间碰撞。
- `s` 表示沿关节空间连接的插值比例；采样数量决定相邻检查姿态之间的角度间隔。
- `False` 表示至少一个检查点已发现无效；`True` 只表示当前有限采样点未发现问题。
- 更密的采样能减少某些漏检，但不提供连续安全的数学证明；数值容差也不能代替实际安全裕量。
