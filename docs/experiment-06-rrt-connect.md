# 实验 06：RRT-Connect 双树规划与阶段验收

> 整理日期：2026-10-23。依据学习者实现与运行反馈、AI 封装及内存验证的实际结果整理。实现完成和案例通过不等于全部概念已经独立掌握。

## 问题与预测

- **问题：** 在不铺设关节网格的情况下，通过随机采样与两棵树的连接，寻找平面二连杆的避障路径；检验路径拼接、随机种子复现及失败处理。
- **方法预期：** 不同种子可能生成不同可行路径；相同配置和种子应重复产生相同结果。基础 RRT-Connect 不保证最短，预算耗尽不等于连续空间无解。
- 学习者已解释：父节点是扩展来源；碰撞候选不入树；多轮探索保留已有节点；两段路径拼接应去掉重复接点。完整多种子实验的个人事前预测未留存，不补造。

### 场景、接口及指标

| 项目 | 设置 |
| --- | --- |
| 两杆长度 | 0.30 m、0.25 m |
| 障碍物 | 圆心 (0.15, 0.08) m，半径 0.04 m |
| 杆半径 | 0.01 m |
| 关节限位、采样范围 | 两关节均为 ±150°，不做周期绕回 |
| 起点 | [0°, 0°] |
| 目标 | [-75°, -150°] |
| 步长 | 关节角欧氏距离最多 10°，内部为弧度 |
| 连接检查 | 每段 11 点，包含首尾；正常扩展的相邻采样角距离不超过 1° |
| 搜索预算 | 最多 1000 个外层尝试，不是总共最多 1000 次单步扩展 |
| 种子 | 基本演示 42，多次运行 0～29 |
| 路径代价 | 各段关节角欧氏距离之和，单位 rad |

`extend_once` 找最近节点、限步前进，通过连接检查才追加姿态和父索引。目标已存在时返回已有索引，不增加重复节点。

`connect` 朝固定目标连续调用 `extend_once`，到达返回索引，受阻返回 None；受阻前成功加入的节点保留。

`rrt_connect` 按尝试轮数奇偶交替主动树。主动树朝随机目标走一步，另一棵树朝刚获得的新姿态连续连接。接通后分别回溯，拼成起点到目标的弧度姿态列表；无效输入或预算耗尽返回 None。输出后的逐段复核由示例执行。

本次收尾增加唯一行为修正：两个根姿态有效且距离小于 `1e-12 rad` 时，直接返回起点副本组成的单节点路径，避免离开再返回。其余搜索与回溯逻辑保留。

### 验证方式

- AI 在内存中运行 30 个种子，每个种子重复运行并比较完整返回数组。
- 对返回路径核对起终点、姿态有效性及所有连接；代价由路径重新计算。
- 基础多种子验证采用同一个姿态和连接接口，不构成独立几何实现对照。
- 特定分支通过运行时跟踪确认接通发生在奇数 attempt（第 2 轮），不修改算法以强迫分支通过。
- 验证使用 `-B`，不创建验证脚本、原始日志或字节码文件；下表为实际运行摘要。当前尚无保存这些批量验证的自动评测入口。

多种子复现的调用形式：

```python
import numpy as np
from RRT_Connect import rrt_connect

for seed in range(30):
    path = rrt_connect(
        np.deg2rad([0.0, 0.0]),
        np.deg2rad([-75.0, -150.0]),
        a1=0.30, a2=0.25, xc=0.15, yc=0.08,
        r=0.04, rod_radius=0.01,
        step_size=np.deg2rad(10.0), sample_count=11,
        max_iterations=1000, seed=seed,
    )
```

## 结果

### 成功与随机性

| 指标 | 实际结果 |
| --- | --- |
| 种子 0～29 成功次数 | 30/30，限本场景和预算 |
| 相同种子重复结果 | 30/30 完整姿态数组相同 |
| 路径端点、姿态与连接复核 | 全部通过 |
| 节点数范围 | 18～20 |
| 路径代价最小值 | 2.927197416 rad |
| 路径代价最大值 | 3.275486861 rad |
| 路径代价平均值 | 3.111007578 rad |
| 种子 42 | 20 个姿态，19 段连接全部通过复核 |

基本场景的 30 个种子均在第 1 轮接通，因此这些运行本身不足以覆盖树角色交换后的回溯分支，也不能说明复杂场景成功率相同。

RRT 的路径允许同时改变两个关节，之前 A* 使用四邻居轴向边；两者代价不同不能直接得出“RRT 比 A* 更优”的结论。公平质量和计算开销比较仍待专门设计。

### 另一侧主动接通分支

- 障碍物、杆长、步长、采样数量保持不变。
- 起点角度：`[7.974980336773882, 100.25607349122163]` 度。
- 目标角度：`[-75, 150]` 度。
- 种子 14，最多 60 轮。
- 实际在第 2 轮（attempt=1，目标树为主动树）接通，返回 11 个姿态。
- 端点方向正确，两边接点一致，全部返回连接通过 11 点复核。这验证了交换角色后索引映射和回溯拼接分支。

### 边界与失败

| 情况 | 实际结果 |
| --- | --- |
| 起点 [0°,150°] 无效 | 返回 None |
| 目标 [0°,150°] 无效 | 返回 None |
| 起终点有效，预算为 0 | 返回 None |
| [0°,0°] → [60°,0°]，种子 42，预算 1 | 两端有效，本次预算耗尽返回 None |
| 起终点均为 [0°,0°] | 修正后返回单节点，代价 0；数组为独立副本 |
| Connect 朝 [0°,-25°]，步长 10° | 学习者验证依次到 -10°、-20°、-25°，父索引 [None,0,1,2] |
| Connect 朝 [60°,0°]，步长 10° | 学习者验证返回 None，但保留 [0°,0°]、[10°,0°] |

原来的起终点重合案例会返回“起点 → 新节点 → 起点”三节点路径，代价约 0.349066 rad；不是碰撞错误，但存在无意义绕行。提前重合判断后，此问题修复，30 种子原案例复跑仍全通过。

## 修正与理解

### 调试与修正

- 初期把 tree、trees 及 new_nodes 混用，父索引还套入额外列表；统一为同一 tree 与 parents 后，姿态和父索引按位置对应。
- 最近邻循环缩进、先使用 None 索引、未每轮重算方向等问题，通过代码审阅与输出修正。
- Connect 初版误把树根当作固定扩展目标，且递归重复调用；改用 q_target、参数透传和循环推进。
- 输出路径的判断一度放在外层搜索循环内，成功 break 后无法打印；移至循环外。
- 理解并使用 `path_start + path_goal[1:]` 避免重复接点；复核必须在路径定义后的成功分支执行。

### 理解与局限

- 随机的是探索目标，实际新节点由最近姿态、方向与步长计算，不是直接把随机目标加入树。
- 树节点代表整条机械臂的关节姿态，树边代表通过当前离散检查的连接；树不是末端的现实空间轨迹。
- nearest 使用角度差向量的欧氏范数，parent 记录生成来源，而不是当前最近邻。
- 基础算法寻找可行路径，不保证最短；搜索预算失败不代表无解。
- 11 点复核不提供连续安全证明；当前未引入工程安全裕量。
- 步长须为正、树须非空、数组形状与数值须有效，这些为当前调用前提，尚未实现完整通用参数校验。固定采样点数也尚未随用户改动步长自动调整。
- 自碰撞、多障碍、不同拓扑、复杂窄通道和独立碰撞验证仍不属于本次已验收范围。
