# 项目设计边界（待逐步实现）

## 模型约定

- 水平面 2R，杆长 0.30 m、0.25 m，关节绕 +Z，零位沿 +X。
- q1 相对世界坐标，q2 相对第一杆；内部统一使用 m、rad、s。
- 两关节初始限位 ±150°，不跨限位边界绕回。
- 静态圆形障碍物；连杆考虑厚度。相邻杆共享关节处不计自碰撞；不声称覆盖底座及任意自碰撞。
- 质量、惯量、阻尼、力矩与速度限制在动力学阶段统一选定，写明教学假设，并与 MuJoCo 对齐。

## 模块职责

未来逐步形成模型、碰撞检测、规划、轨迹、控制、评测模块。先完成最小实验，再提取公共接口，不提前写空壳类堆砌架构。

规划模块返回路径或明确失败原因；轨迹模块给出目标位置、速度、加速度；控制模块根据实际状态给出力矩；评测模块区分计划与执行结果。

## 最终评测要求

- 场景：空旷、单障碍、多障碍、窄通道、无解、无效输入。
- 规划：成功率、耗时、关节空间路径长度、最小间隙、碰撞检查次数。
- 控制：关节 RMSE、最大误差、峰值力矩、饱和时间比例、实际间隙、执行成功率。
- 记录配置、种子、依赖和提交号。调试与评测场景分开，不为评测逐场景调参。
- 指定标称演示的目标：无碰撞到达，各关节终点误差 < 0.02 rad；失败也如实记录。
- 离散边检查有分辨率局限；不宣称连续安全证明。规划超预算只能说明未找到路径。

## 发布时必须说清的局限

只有仿真，没有真机验证；模型和障碍物已知；水平二连杆不代表六轴应用；路点停顿轨迹不代表工业级平滑最优解；力矩限幅可能破坏理想跟踪性能。
