# 验证

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

- test_kinematics.py：解析逆解双分支回代、不可达点、原速度实验、逐列中心差分、输入校验和静默导入。
- test_inverse_jacobian.py：原数值逆解实验、输入不被修改、零次更新、最后一次更新后的收敛检查、奇异初值失败和无效参数。

原代码中的实验断言由助手按用户要求迁移，中心差分与边界回归检查由助手补充。
这些检查验证现有实现，不代表学习者已独立编写测试或掌握相关知识。
三组姿态的个人手算、双解与奇异姿态的解释仍需学习者记录。
